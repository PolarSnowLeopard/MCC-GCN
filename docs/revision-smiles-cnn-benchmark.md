# SMILES CNN revision benchmark

The three-API revision benchmark includes an independently implemented,
dual-branch SMILES convolutional neural network. Its role is to address the
reviewer request for a CNN comparison and randomized-SMILES augmentation.

## Design

- Each molecule is represented as a tokenized SMILES sequence.
- Separate convolutional encoders process the two molecular components.
- Their pooled representations are concatenated and classified by a dense
  interaction head.
- Training retains every physical pair and uses effective-number class
  weighting. It does not undersample the majority classes.
- Multiple deterministic randomized SMILES variants are generated by changing
  the root atom used for graph traversal.
- Physical pairs are split before either SMILES randomization or A/B order
  augmentation.
- Both A/B and B/A orders are used during training; their probabilities are
  averaged during validation and testing.
- Fine-tuning freezes both molecular encoders and updates only the interaction
  classifier, mirroring the classifier-only adaptation used for MCC-GCN.

This implementation follows the public architectural description of a
two-branch SMILES CNN in DeepCocrystal but does not copy or redistribute the
official code. The official repository uses the Academic Software Licence,
which limits use to academic non-commercial settings and is not suitable for
incorporation into this repository.

## Smoke test

The development smoke test covers pretraining, zero-shot evaluation,
fine-tuning selection, final fitting, orientation-averaged prediction, and
result aggregation. It uses a deliberately tiny source subset and one outer
fold and is not a scientific result.

## Formal run

Run this only after the MCC-GCN learning-curve experiment has released the GPU:

```bash
RUN_ID="revision-three-api-smiles-cnn-$(date +%Y%m%d-%H%M%S)"
python scripts/run_target_api_smiles_cnn.py \
  --data-root data/revision-three-api \
  --output-dir "runs/$RUN_ID" \
  --tasks binary,four-class \
  --seeds 42,43,44 \
  --folds 5 \
  --tensorboard-root "/primus_oss/summary/mcc-gcn/$RUN_ID" \
  2>&1 | tee "$RUN_ID.log"
```

The prediction files retain the probability vectors from both component
orders, the averaged probability vector, label agreement, and total-variation
discrepancy. The final directory also contains pooled and per-API metrics for
each seed and a multi-seed aggregate table.
